About the registry

The Decentralised Discovery Gateway is a service offering plug-and-play message and data federation across different nodes. Each node controls user authorisation autonomously, and networks can outlive the project or portal that created them.

Those networks are local and not controlled by any central authority, so they are often hard to find: you need to know which node to ask and which network you want. This registry lets services running a compatible protocol implementation list their networks and nodes, so people outside the project can find and join them.

List your network

Gateways register a network through the API. A registration carries a proof-of-work solution, and later changes are signed with the network's management key. New registrations may wait for an administrator's approval before they appear in the list.
